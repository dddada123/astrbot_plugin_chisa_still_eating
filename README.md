## 🎨 云端皮肤印象色 (4.2.3)

4.2.3 支持从官方及第三方 `skin/index.json` 条目读取安全的两色预览变量 `--primary` / `--bg` 和商品简介 `desc`。未下载皮肤现在可以在商店卡片上显示自己的主题色块与简介，不再统一回退成当前正在使用皮肤的颜色；下载后的卡片继续读取完整配置中的 `desc`。

这些字段保持 `schema_version: 1`，属于可选扩展。旧皮肤仓库无需修改仍可浏览，旧插件会忽略新增字段；点击“下载 / 更新”会强制刷新完整配置与背景，使已有本地卡片也能取得新简介。远程读取仅使用固定 GitHub/镜像主机，并对重定向与响应大小执行边界检查。

## 🎨 皮肤工坊正式上线 (4.2.0)

4.2.0 将皮肤工坊作为稳定功能正式发布。在四套不可删除的内置皮肤之外，WebUI 同步提供 **官方固定皮肤源** 与 **第三方 GitHub 自定义源**：玩家可以浏览主题、下载或更新皮肤、切换毛玻璃背景，并在“已下载”页面管理本地内容。

- **官方源同步**：官方仓库集中发布经过维护的皮肤商品，打开皮肤管理器即可刷新获取。
- **第三方源订阅**：输入 `owner/repo` 或完整 GitHub 地址即可连接和保存；可同时订阅多个社区皮肤仓库，没有商品时也会显示明确的空状态。
- **来源完全隔离**：官方内容保存到 `Webui-PIC/skins/OfficialWS/skin`，第三方内容保存到各自的 `<owner>_<repo>/skin`；不同来源可以使用相同皮肤 ID，删除时互不影响。
- **大图稳定加载**：背景下载到本地后通过分块传递到 WebUI，数 MB 的 JPG/PNG 不再因为单次 base64 响应过大而无法显示。
- **启动不再等待背景**：WebUI 优先读取和渲染本地图库，红枫背景下载及分块装配在后台进行；下载节点卡顿也不会把用户困在初始界面。
- **格式向前兼容**：支持传统 14 变量皮肤及带 `--primary-contrast` 的 15 变量皮肤，旧商品无需重新制作。

皮肤仓库按 `skin/index.json`、`skin/{id}.json` 和配置中的 `assets.bg` 组织资源。当前皮肤 ID、来源和毛玻璃力度会持久化保存，刷新或重开 WebUI 后仍可恢复。配套的“千小妹后厨”图形化打包器也已加入皮肤商品制作、编号编辑及已有商品更新能力；打包器的详细 README 在独立项目中维护，本仓库仅介绍播放器端功能。

## 🌟 核心特色与功能

1. **🎲 多世界盲盒摇号引擎**
   无论是 **三次元外卖**，还是 **鸣潮、原神、终末地** 的游戏特产，用户只需发送一句 吃什么 或 喝什么，系统将自动根据后台配置的概率进行跨界随机抽取。
   - 带有防重复历史记忆机制，连续点餐不重样！
   - 特供"冷热食智能替换"与"黑暗料理池"作死玩法！

2. **🌍 定向打卡与专属召唤**
   - **锁定世界**：输入 鸣潮特产 / 原神特饮，即可强行锁定目标世界进行抽取。
   - **专属羁绊召唤**：输入 召唤爱弥斯下厨 / 弗洛洛特供料理，系统将绕过常规大池子，直接且唯一地为你端上由该厨师亲手制作的食物（并自动附带专属表情包立绘）。

3. **🥷 截胡防刷屏系统**
   不仅拥有防刷屏冷却，在用户高速点餐时，甚至会有概率被**千咲（或其他干饭人）**强行出场把饭抢光，极大增加群聊节目效果！

4. **☁️ 纯净代码与安全部署**
   插件本体轻如鸿毛，代码与图库彻底剥离！
   通过内置的 SHA-256 安全校验下载引擎（99.2MB 轻量化基础包，带国内四镜像智能测速与 GitHub 直链兜底），**管理员通过 WebUI 一键进货或群内一条指令，系统就会在后台安全拉取图库包并全自动解压部署**！再也不用对着压缩包发愁！

5. **👑 全自动化群内图库管理（无需动后台）**
   拥有白名单权限的群管，可以直接在群内通过指令实时丰富图库，**支持多图批量发送**！
   - 例如我的Bot唤醒词是小爱，就可以通过输入："小爱加菜 鸣潮 食物 【大远哥】土鸡蛋[图片]"这样添加厨师为大远哥的专属料理土鸡蛋，注意中间一定要加空格。
   - 输入"小爱加菜 三次元 食物 土鸡蛋[图片]"则会增加没有厨师识别的土鸡蛋图片到三次元图片库。
   - 上传厨师则直接输入："上传厨师 莫宁[图片]"即可添加莫宁的立绘/动图到厨师，摇到莫宁专属料理的时候就可以概率发出厨师对应的动图伙食立绘。
   - 食物和厨师也都支持gif动图发送，如果你有非常报社的美味食物动图，一个小技巧，给你喜欢的图片加上对应的厨师上传入库，就可以通过"召唤[厨师]下厨"、"[厨师]特供料理"的命令发出特定的图片馋哭群友！

## 🚀 安装与部署指南

### 第一步：安装插件本体
在 AstrBot 官方应用商店直接搜索本插件并点击一键安装。或者直接克隆本仓库到 data/plugins/ 下。

### 第二步：部署图库（二选一）

**选项 A：WEBUI 商城一键进货（推荐）**
1. 打开 AstrBot 管理面板，进入本插件的 **「千小妹商会」** 页面。
2. 点击 **「🔄 刷新货架」** 拉取线上目录（首次使用会自动同步）。
3. 找到 **【食品】\*\*重要\*\*基础资源包**（fd0000，约 99.2MB），点击 **「⬇️ 下载部署」**。
4. 系统将走四镜像智能测速高速下载，SHA-256 校验通过后自动解压入库，进度实时播报！

**选项 B：群聊指令部署（管理员）**
1. 在 AstrBot 管理面板的 **插件配置** 中，在 **"管理员账号白名单"** 里填入你的 QQ 号并保存。
2. 对机器人发送指令 更新千小妹图库。
3. 系统将在后台安全拉取图库包（99.2MB，带国内镜像加速与 SHA-256 防投毒校验）。期间可通过指令 千小妹图库下载进度 实时查看 MB 级进度。等待解压完成即可立刻使用！

**选项 C：手动极速兜底部署（若网络环境极端恶劣）**
1. 前往 [图库仓库 Releases](https://github.com/dddada123/astrbot_plugin_chisa_still_eating_photo/releases/tag/Chisa_Dlc_Store) 页面下载 **fd0000.zip**（约 99.2MB）。
2. 将下载好的压缩包解压，把里面的 food、drink、chefs 等文件夹，放入 data/plugin_data/astrbot_plugin_chisa_still_eating/ 目录下。
3. 重启 AstrBot 即可。

## 🛠️ MOD 与高阶自定义玩法（不过现在基本都可以通过WEBUI管理咯）

本插件致力于"物理级免配置"的优雅体验：所有资源的扩充、修改、干饭人的添加，**完全不需要修改任何 JSON 文件**，直接将文件拖入对应的目录即可生效！

### 📂 物理资源库目录说明
基础图库解压后，所有资源均存放在机器人根目录下的：
data/plugin_data/astrbot_plugin_chisa_still_eating/

* **food/（食物图库）与 drink/（饮品图库）**：
  - 子目录如 common（三次元/现实）、world1（世界一）、world2（世界二）等。
  - **如何加菜**：直接把图片拖进对应文件夹即可。
  - **如何触发厨师专属**：只需将图片命名为带 【厨师名】 的格式（如：【香菱】水煮黑背鲈.png），系统摇到这道菜时就会自动触发"香菱"专属的登场台词与立绘。

* **chefs/（厨师立绘图鉴）**：
  - 存放各路大厨的单人立绘（如：香菱.jpg）。当抽中该厨师的菜时，系统会自动在此目录寻找同名图片并展示。直接放入同名图片即可添加或替换！

* **memes/（导游情绪映射库）**：
  机器人（向导）的反应会根据抽卡结果**动态变化**（按世界观 world1 等分类存放）：
  - like/：抽中普通美食时发送（欢快/推荐）。
  - scared/：触发"黑暗料理"时发送（惊恐/抗拒/防毒面具）。
  - think/：频繁重复触发冷却机制时发送（发呆/摆烂）。
  - speechless/：疯狂点菜触发防刷屏警报时发送（无语/制止）。

### 🏃‍♂️ 实战案例：如何创建你的专属"MOD 干饭人"？
如果群友刷屏点菜，会触发神秘人"截胡"把饭抢走。你可以自由创造抢饭的人（干饭人）：
以添加《公主连结》中的**佩可莉姆**为例，只需三步：
1. **新建目录**：在图库的 ganfanren/ 目录下，新建一个文件夹，命名为 佩可莉姆。
2. **放入表情包**：将准备好的佩可莉姆抢饭表情包（支持 .png, .jpg, .gif）直接拖入该文件夹。图片越多，随机抽取的表情越丰富！
3. **编写专属语录**：在 佩可莉姆 文件夹内新建一个文本文件 words.txt。打开它，按照"一行一句话"的格式写入她的抢饭台词（比如："欧伊西！这顿饭我佩可就收下啦！"）。
**完成！系统会自动扫描并让她加入抢饭大军（你也可以在 WebUI 的配置面板中指定让她必定出场）。**
