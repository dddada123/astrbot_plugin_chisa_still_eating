# 🚀 🍱 千小妹还在吃 (Chisa Still Eating)
[![AstrBot](https://img.shields.io/badge/Framework-AstrBot-🚀_purple.svg)](https://github.com/Soulter/AstrBot)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

一个为 [AstrBot](https://github.com/Soulter/AstrBot) 深度定制的跨次元多世界干饭系统。
每天都在纠结吃什么？那就让异次元的向导们来帮你随机摇号吧！把食物图片扔进对应的文件夹，它就会自动变成菜单里的美味！通过完美的分类引擎，为你的群聊带来极具情感连接和随机惊喜的沉浸式“吃什么”体验！

当前版本：3.5.3 | 作者：Rua432

## 🌟 核心特色与功能

1. **🎲 多世界盲盒摇号引擎**
   无论是 **三次元外卖**，还是 **鸣潮、原神、终末地** 的游戏特产，用户只需发送一句 吃什么 或 喝什么，系统将自动根据后台配置的概率进行跨界随机抽取。
   - 带有防重复历史记忆机制，连续点餐不重样！
   - 特供“冷热食智能替换”与“黑暗料理池”作死玩法！

2. **🌍 定向打卡与专属召唤**
   - **锁定世界**：输入 鸣潮特产 / 原神特饮，即可强行锁定目标世界进行抽取。
   - **专属羁绊召唤**：输入 召唤爱弥斯下厨 / 弗洛洛特供料理，系统将绕过常规大池子，直接且唯一地为你端上由该厨师亲手制作的食物（并自动附带专属表情包立绘）。

3. **🥷 截胡防刷屏系统**
   不仅拥有防刷屏冷却，在用户高速点餐时，甚至会有概率被**千咲（或其他干饭人）**强行出场把饭抢光，极大增加群聊节目效果！

4. **☁️ 纯净代码与半自动安全部署**
   v3.5 Beta 实现了代码与图库的彻底剥离！插件本体轻如鸿毛。
   通过内置的 SHA-256 安全校验下载引擎，**管理员只需在群内发送一条指令，系统就会在后台安全拉取 160MB 的图库包并全自动解压部署**！再也不用对着压缩包发愁！

5. **👑 全自动化群内图库管理（无需动后台）**
   拥有白名单权限的群管，可以直接在群内通过指令实时丰富图库，**支持多图批量发送**！
   - 加菜 鸣潮 食物 【吟霖】雷云蛋挞 （附加图片）
   - 上传厨师 吟霖 （附加图片）

## 🚀 安装与部署指南

### 第一步：安装插件本体
在 AstrBot 官方应用商店直接搜索本插件并点击一键安装。或者直接克隆本仓库到 data/plugins/ 下。

### 第二步：部署图库（二选一）

**选项 A：半自动安全部署（推荐）**
为符合平台安全规范，插件去除了开机自动后台下载，改为由管理员指令触发：
1. 在 AstrBot 管理面板打开 **插件配置 (WebUI)**，在 **“管理员账号白名单”** 中填入你的 QQ 号并保存。
2. 对机器人发送指令 更新千小妹图库。
3. 系统将在后台安全拉取图库包（160MB，带国内镜像加速与 SHA-256 防投毒校验）。期间可通过指令 千小妹图库下载进度 实时查看 MB 级进度。等待解压完成即可立刻使用！
*(注：你也可以直接在 WebUI 勾选最上方的“强制重新下载基础图库”来触发下载。❗下载完成后请务必取消勾选并保存，以免每次重启都重复下载！)*

**选项 B：手动极速兜底部署（若指令拉取失败/超时）**
1. 前往[本插件的 GitHub Releases ](https://github.com/dddada123/astrbot_plugin_chisa_still_eating_photo/releases/tag/v3.0-beta)页面，或通过下方的网盘链接，下载 V3.astrbot_plugin_chisa_still_eating.zip (约 160MB)。
   - [夸克网盘下载](https://pan.quark.cn/s/301110d45a48)
   - [百度网盘下载](https://pan.baidu.com/s/1ZHfYz8vNL5JU0jyFtHiYqQ?pwd=erm9) 提取码：erm9
2. 将下载好的压缩包解压，把里面的 food、drink、chefs 等文件夹，放入 data/plugin_data/astrbot_plugin_chisa_still_eating/ 目录下。
3. 重启 AstrBot 即可。

## 🛠️ MOD 与高阶自定义玩法（物理免配指南）

本插件致力于“物理级免配置”的优雅体验：所有资源的扩充、修改、干饭人的添加，**完全不需要修改任何 JSON 文件**，直接将文件拖入对应的目录即可生效！

### 📂 物理资源库目录说明
基础图库解压后，所有资源均存放在机器人根目录下的：
data/plugin_data/astrbot_plugin_chisa_still_eating/

* **food/（食物图库）与 drink/（饮品图库）**：
  - 子目录如 common（三次元/现实）、world1（世界一）、world2（世界二）等。
  - **如何加菜**：直接把图片拖进对应文件夹即可。
  - **如何触发厨师专属**：只需将图片命名为带 【厨师名】 的格式（如：【香菱】水煮黑背鲈.png），系统摇到这道菜时就会自动触发“香菱”专属的登场台词与立绘。

* **chefs/（厨师立绘图鉴）**：
  - 存放各路大厨的单人立绘（如：香菱.jpg）。当抽中该厨师的菜时，系统会自动在此目录寻找同名图片并展示。直接放入同名图片即可添加或替换！

* **memes/（导游情绪映射库）**：
  机器人（向导）的反应会根据抽卡结果**动态变化**（按世界观 world1 等分类存放）：
  - like/：抽中普通美食时发送（欢快/推荐）。
  - scared/：触发“黑暗料理”时发送（惊恐/抗拒/防毒面具）。
  - think/：频繁重复触发冷却机制时发送（发呆/摆烂）。
  - speechless/：疯狂点菜触发防刷屏警报时发送（无语/制止）。

### 🏃‍♂️ 实战案例：如何创建你的专属“MOD 干饭人”？
如果群友刷屏点菜，会触发神秘人“截胡”把饭抢走。你可以自由创造抢饭的人（干饭人）：
以添加《公主连结》中的**佩可莉姆**为例，只需三步：
1. **新建目录**：在图库的 ganfanren/ 目录下，新建一个文件夹，命名为 佩可莉姆。
2. **放入表情包**：将准备好的佩可莉姆抢饭表情包（支持 .png, .jpg, .gif）直接拖入该文件夹。图片越多，随机抽取的表情越丰富！
3. **编写专属语录**：在 佩可莉姆 文件夹内新建一个文本文件 words.txt。打开它，按照“一行一句话”的格式写入她的抢饭台词（比如：“欧伊西！这顿饭我佩可就收下啦！”）。
**完成！系统会自动扫描并让她加入抢饭大军（你也可以在 WebUI 的配置面板中指定让她必定出场）。**
