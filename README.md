# 🚀 🍱 千小妹还在吃 (Chisa Still Eating)
[![AstrBot](https://img.shields.io/badge/Framework-AstrBot-🚀_purple.svg)](https://github.com/Soulter/AstrBot)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

一个为 [AstrBot](https://github.com/Soulter/AstrBot) 深度定制的跨次元多世界干饭系统。
每天都在纠结吃什么？那就让异次元的向导们来帮你随机摇号吧！把食物图片扔进对应的文件夹，它就会自动变成菜单里的美味！通过完美的分类引擎，为你的群聊带来极具情感连接和随机惊喜的沉浸式“吃什么”体验！

当前版本：3.1 Beta | 作者：Rua432

---

## 🌟 核心特色与功能

1. **🎲 多世界盲盒摇号引擎**
   无论是 **三次元外卖**，还是 **鸣潮、原神、终末地** 的游戏特产，用户只需发送一句 吃什么 或 喝什么，系统将自动根据后台配置的概率进行跨界随机抽取。
   - 带有防重复历史记忆机制，连续点餐不重样！
   - 特供“冷热食智能替换”与“黑暗料理池”作死玩法！

2. **🌍 定向打卡与专属召唤**
   - **锁定世界**：输入 鸣潮特产 / 原神特饮，即可强行锁定目标世界进行抽取。
   - **专属羁绊召唤**：输入 召唤达妮娅 / 刻晴料理，系统将绕过常规大池子，直接且唯一地为你端上由该厨师亲手制作的食物（并自动附带专属表情包立绘）。

3. **🥷 截胡防刷屏系统**
   不仅拥有防刷屏冷却，在用户高速点餐时，甚至会有概率被**千咲（或其他干饭人）**强行出场把饭抢光，极大增加群聊节目效果！

4. **☁️ 纯净代码与自动部署**
   v3.1 Beta 实现了代码与图库的彻底剥离！插件本体轻如鸿毛。
   安装后将**自动从 GitHub 后台拉取图库包（160MB）并完成解压部署**！再也不用对着压缩包发愁！

5. **👑 全自动化群内图库管理（无需动后台）**
   拥有白名单权限的群管，可以直接在群内通过指令实时丰富图库，**支持多图批量发送**！
   - 加菜 鸣潮 食物 【吟霖】雷云蛋挞 （附加图片）
   - 上传厨师 吟霖 （附加图片）

## 🚀 安装与部署指南

### 第一步：安装插件本体
在 AstrBot 官方应用商店直接搜索本插件并点击一键安装。或者直接克隆本仓库到 data/plugins/ 下。

### 第二步：部署图库（二选一）

**选项 A：系统自动部署（推荐）**
1. 在 AstrBot 安装完插件后，直接重启 AstrBot。
2. 重启后插件检测到图库为空，会**自动在后台开始从 Github Releases 拉取图库**（带有镜像加速代理）。
3. 这期间在群里发送指令，系统会温馨提示“正在下载解压中…”。等待部署完成即可立刻使用！

**选项 B：手动极速部署（如果自动拉取失败/超时）**
1. 前往本插件的 GitHub Releases 页面，或通过下方的网盘链接，下载 V3.astrbot_plugin_chisa_still_eating.zip (约 160MB)。
   - [夸克网盘下载](https://pan.quark.cn/s/301110d45a48)
   - [百度网盘下载](https://pan.baidu.com/s/1ZHfYz8vNL5JU0jyFtHiYqQ?pwd=erm9) 提取码：erm9
2. 在 AstrBot 管理面板打开**插件配置 (WebUI)**，将最上方的 **“强制重新下载基础图库”** 取消勾选并保存。
3. 将下载好的压缩包解压，把里面的 ood、drink、chefs 等文件夹，放入 data/plugin_data/astrbot_plugin_chisa_still_eating/ 目录下。
4. 重启 AstrBot 即可。

## 🎮 指令速查表

| 指令 | 效果说明 |
| --- | --- |
| 吃什么 / 喝什么 | 全宇宙概率盲盒摇号 |
| 来点现实的食物/饮品 | 锁定三次元池子 |
| [别名]特产 / 特饮 | 锁定抽取指定世界的食物或饮料 (例如: 鸣潮特饮) |
| 召唤[厨师名] | 指定抽取某位厨师的专属料理 (例如: 召唤安柏) |
| [厨师名]料理 / 特供 | 同上，定向召唤专属 |
| 来点黑暗料理 | 从特殊池子随机抽取（小心被毒死） |
| 千小妹还在吃帮助 | 获取完整的群内文字帮助菜单 |
| 加菜 [世界] [分类] [菜名] [图] | **[管理员专属]** 群内实时增加菜品入库 |
| 上传厨师 [厨师名] [图] | **[管理员专属]** 群内实时添加厨师表情包/立绘 |

> **提示：**上传厨师 和 加菜 命令前面哪怕带有机器人的唤醒词（如 小爱上传厨师刻晴）也能完美识别并触发，并且不需要强制带斜杠！

## ⚙️ 配置文件 (WebUI)
支持通过 AstrBot 的 WebUI 进行极其详细的自定义设置：
- **权重分配**：精确到数字的三次元、世界1、世界2等各卡池的抽取概率控制。
- **自定义别名**：随心所欲设定“原神”、“提瓦特”等作为特定世界的触发词。
- **AI拟人接入**：允许配置大模型以特定人设（推荐官/向导等）为您进行菜品播报。
- **黑白名单系统**：精确控制群聊权限，避免恶意刷屏。
